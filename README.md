# Save Xiaohongshu Note — Codex Skill

将单条或批量小红书笔记归档为 Markdown，并支持下载原图、读取 CSV/TSV/TXT/Markdown/XLSX 链接清单、保留运营标签与内容分类、断点续传和导出报告。

## 安装

把本仓库链接发送给 Codex：

```text
请安装这个 skill：<本仓库链接>/tree/main/save-xiaohongshu-note
```

也可以下载仓库 ZIP，然后把 `save-xiaohongshu-note` 文件夹复制到：

```text
~/.codex/skills/
```

安装后重新打开一个 Codex 任务，通过 `$save-xiaohongshu-note` 调用。

## 使用示例

```text
使用 $save-xiaohongshu-note 批量导出这个表格。

这些都是我自己的笔记，可以完整归档正文和原图。
请把运营标签和内容分类加入文件名与 Markdown 标题。
```

完整正文和图片仅应用于本人作品或已获授权的内容；不得绕过登录、验证码、私密内容或平台访问限制。
